# Clothify – Local Business Landing Page

## Project Overview

**Clothify** is a fictional local clothing business designed to provide modern and affordable fashion for young adults.

This project was developed as part of the **Thrive Africa Frontend Development Essentials Course – Local Business Landing Page Capstone**.

The website is a simple, single-page landing page that introduces Clothify, presents its fashion services, showcases recent work, explains how the business works, and provides customers with a way to make an enquiry.

### Project Details

- **Business Name:** Clothify
- **Business Type:** Clothing/Fashion
- **Business Status:** Fictional
- **Target Audience:** Young adults
- **Location:** Accra, Ghana
- **Technologies:** HTML, CSS, JavaScript
- **Project Type:** Individual project

## Features

The website contains the following sections:

### 1. Navigation

The navigation menu provides links to the main sections of the website:

- Home
- Services
- Recent Work
- Contact

The navigation allows visitors to move easily between different sections of the page.

### 2. Hero Section

The hero section introduces Clothify with the headline:

> **Style That Speaks For You**

It also includes a short description of the business, a **View Services** call-to-action button, and a relevant fashion image.

### 3. Our Services

The services section presents three main offerings:

- **Men's Fashion** – Stylish shirts, trousers, jackets, and other men's clothing.
- **Women's Fashion** – Modern dresses, tops, skirts, and other fashionable outfits.
- **Custom Styling** – Assistance with choosing outfits that match a customer's personal style and occasion.

### 4. How We Work

This section explains the customer journey through three simple steps:

1. **Enquire** – Contact Clothify or visit the store to discuss what you are looking for.
2. **Choose** – Browse the available clothing and select what matches your style.
3. **Get Your Style** – Complete the purchase and leave with an outfit you love.

### 5. Recent Work

The Recent Work section showcases three fashion examples:

- **Classic Men's Outfit**
- **Elegant Women's Outfit**
- **Casual Collection**

Each example contains an image, title, and short description.

### 6. Contact Us

The contact section allows visitors to make an enquiry through a simple contact form.

The form contains:

- Name
- Email
- Message
- Send Message button

The section also provides the business location, phone number, and email address.

### 7. Footer

The footer contains the Clothify business name, copyright information, location, and contact number.

## JavaScript Interaction

JavaScript is used to provide **contact form validation and feedback**.

When a visitor submits the contact form, JavaScript checks whether the **name** and **message** fields have been completed.

- If the name or message is empty, the user receives an alert asking them to fill in the required information.
- If the required fields are completed, the user receives a confirmation message.
- The form is then reset after successful submission.

The form does not send an actual email or message. It is a demonstration of JavaScript form interaction.

### How to Test the JavaScript

1. Scroll to the **Contact Us** section.
2. Leave the name or message field empty.
3. Click **Send Message**.
4. An alert will ask you to fill in your name and message.
5. Enter your name and message.
6. Click **Send Message** again.
7. A confirmation message will appear and the form will be cleared.

## Design and Inspiration

The design of Clothify was created from my own ideas and preferences. No specific external website was used as the main design reference.

The design focuses on creating a simple, clean, and modern fashion landing page that is easy for young adults to navigate.

### Colour Scheme

The website uses a simple colour palette consisting mainly of:

- Black
- White
- Light grey
- Gold/yellow

The gold colour is used to highlight important interactive elements such as the main call-to-action button.

### Typography

The website uses the **Arial** font family to keep the text simple and readable.

### Layout

CSS Flexbox was used to arrange major elements of the website, including:

- Navigation
- Hero section
- Service cards
- How We Work section
- Recent Work section

The design also uses spacing, rounded corners, images, and contrasting backgrounds to separate the different sections.

## Responsive Design

The website includes responsive CSS using a media query for screens below **768px**.

The mobile layout changes the arrangement of several elements to make the website easier to use on smaller screens.

For example:

- The navigation changes to a vertical layout.
- The hero section changes from a horizontal layout to a vertical layout.
- Service cards are stacked vertically.
- The How We Work cards are stacked vertically.
- Recent Work items are stacked vertically.
- The hero heading is reduced in size.

The responsive design was tested on a mobile-sized screen to check that the layout worked correctly.

## Development Process

The project was developed step by step using HTML, CSS, and JavaScript.

### Step 1 – Business Selection

I selected a fictional clothing business called **Clothify**. The main target audience was young adults interested in modern and affordable fashion.

### Step 2 – Planning

I planned the main sections of the landing page:

- Home
- Services
- How We Work
- Recent Work
- Contact
- Footer

I also decided on the general colour scheme, layout, content, and images before developing the page.

### Step 3 – HTML Development

I created the main structure of the website using HTML.

Semantic sections and IDs were used so that the navigation links could take visitors to the appropriate parts of the page.

### Step 4 – CSS Styling

CSS was then used to create the visual design.

I used Flexbox to arrange the main sections and created styling for the navigation, hero section, service cards, recent work, contact form, and footer.

### Step 5 – JavaScript

I added JavaScript functionality to the contact form.

This was one of the more challenging parts of the project because I had to understand how JavaScript interacts with HTML elements and how to use JavaScript together with CSS and the rest of the webpage.

### Step 6 – Responsive Design

I added a CSS media query to make the website adapt to smaller screens.

The mobile layout was then tested to ensure that the major sections displayed correctly.

### Step 7 – Testing

I tested the website to make sure that:

- Navigation links worked.
- The View Services button moved to the Services section.
- Images displayed correctly.
- The contact form worked.
- JavaScript validation worked.
- The responsive layout worked on mobile.
- Buttons and interactive elements responded correctly.

## Challenges

One of the main challenges I experienced while building the project was understanding and implementing the **JavaScript functionality**.

I found it challenging to understand how JavaScript could interact with the HTML form, detect user input, display messages, and reset the form.

Another challenge was understanding how to combine **HTML, CSS, and JavaScript** so that the different parts of the website worked together properly.

Working through these challenges helped me gain a better understanding of how the three technologies can be combined to create an interactive website.

## What I Learned

Through this project, I improved my understanding of:

- Building a webpage with HTML.
- Styling webpages with CSS.
- Using Flexbox for layouts.
- Creating responsive layouts with CSS media queries.
- Working with HTML forms.
- Using JavaScript to interact with HTML elements.
- Performing basic form validation.
- Creating user feedback with JavaScript alerts.
- Combining HTML, CSS, and JavaScript in one project.

## Reflection

Building Clothify gave me practical experience in creating a complete landing page from the initial idea through development and testing.

The JavaScript portion was particularly challenging and demanding, but it helped me understand how JavaScript can make a webpage interactive rather than being only a static design.

I am also proud of being able to create a responsive layout and bring the different sections of the website together into one complete page.

If I had more time, I would add **more functionality** to the project. I would like to make the website more interactive and expand its features beyond the current landing-page functionality.
